會考倒數以台灣當日計算，目標 2027/5/15，會考兩天與結束後各顯示適當提示，跨日與回到頁面會更新。獎勵從原訂 2026/10/23 的任務開始，準時或提前完成 +10 元，逾期未完成或補完成 −5 元，每項只扣一次；當天尚未結束不扣款。舊任務不追算，歷史／取消／封鎖日任務不計；自動搬動仍用原訂日期，不能因搬動重複領取。已完成但缺日期者待確認，暫不計獎扣款。顯示獎勵、扣款、帳面淨額及最低 0 元的累積可領額；尚未扣除已發放款項，也未把全年估計 406 個任務當實際帳本。

完成日期與文字備註在既有 `note` 字串內以 `[cap116-completion-v1]` 加 JSON `{v:1,date,text}` 保存；解析器對舊純文字備註原樣顯示。單一勾選原子更新既有 `read/practice/correct` 三個布林值及 `note`，不新增 Firestore 欄位、不放寬權限。所有畫面／摘要均顯示解碼後的文字；JSON 備份維持 v1 並保留完整編碼，可還原日期。請勿使用舊版頁面編輯新版紀錄（舊版不認識完成日期）。

同一雲端紀錄依操作順序寫入；尚在儲存的改動會保留到同步快照確認，避免舊快照覆蓋完成勾選。家長仍唯讀，登出後不顯示私人獎勵與紀錄；此功能是家庭協作記帳，完成日期可由學生依實際情況更正，並非防竄改的金流系統。
